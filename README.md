# Math Anthology

A curated collection of mathematical problems, proofs, and explorations spanning various branches of mathematics.

## Structure

```
math-anthology/
└── IMO/
    ├── imo-{year}-p{number}.md
    ├── imo-1959-p1.md
    ├── imo-1959-p2.md
    └── ...
```

Files are named `imo-{year}-p{number}` so they sort lexicographically by year then problem number.
