# Math Anthology

A curated collection of mathematical problems, proofs, and explorations spanning various branches of mathematics.

## Structure

```
math-anthology/
└── IMO/
    ├── imo-{year}-p{number}.pdf
    ├── imo-1959-p1.pdf
    ├── imo-1959-p2.pdf
    └── ...
```

Files are named `imo-{year}-p{number}.pdf` so they sort lexicographically by year then problem number.
