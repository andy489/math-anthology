# Math Anthology

A curated collection of mathematical problems, proofs, and explorations spanning various branches of mathematics.

## Contents

| Area | Topics |
|---|---|
| Algebra | Groups, rings, fields, polynomials, linear algebra |
| Analysis | Real and complex analysis, sequences, series, continuity |
| Combinatorics | Counting, graph theory, generating functions |
| Number Theory | Divisibility, primes, modular arithmetic, Diophantine equations |
| Geometry | Euclidean and non-Euclidean geometry, topology |
| Probability | Discrete and continuous probability, stochastic processes |

## Structure

```
math-anthology/
├── algebra/
├── analysis/
├── combinatorics/
├── number-theory/
├── geometry/
└── probability/
```

Each subdirectory contains problem sets, solutions, and notes organized by topic.

## Contributing

Contributions are welcome. Please follow these conventions:

- Place each problem or proof in the appropriate subdirectory.
- Include a clear problem statement, motivation where relevant, and a complete solution.
- Use LaTeX-compatible notation in Markdown (e.g., `$f(x) = x^2$`).
